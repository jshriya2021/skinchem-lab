# SkinChem Lab

A responsive, single-page educational website for an Applied Chemistry project.

## Files
- `index.html` — complete website (HTML, CSS and JavaScript are included in one file).

## Run locally
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Internet is only needed for the optional Google Fonts import and external reference links. The website itself works without a backend.

## Publish with GitHub Pages
1. Sign in to GitHub and create a **public** repository, for example `skinchem-lab`.
2. Upload `index.html` to the repository's root (the top-level folder).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait for the Pages deployment to finish. GitHub will show your public website URL in Settings → Pages. It usually looks like `https://YOUR-USERNAME.github.io/skinchem-lab/`.
